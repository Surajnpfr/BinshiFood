# The Binshi Food Product – Easyeat

## Overview
**The Binshi Food Product** is the parent company of **Easyeat**, a snack brand focused on delivering quality, freshness, and reliable packaging.  
This repository contains the source code for the official product showcase website featuring Easyeat snack products.

## About Easyeat
Easyeat is a product brand under The Binshi Food Product, offering snacks such as:
- Chick Pea (Matar)
- Chana
- Namkeen
- Dalmot
- Bhujia
- Peanuts

All products are designed with an emphasis on taste, hygiene, and durable packaging.

## Tech Stack
- HTML5
- Tailwind CSS (via CDN)
- JavaScript (Vanilla)
- Google Fonts (Plus Jakarta Sans)

## Features
- Responsive modern UI
- Product catalog with size-based pricing
- Wholesale pricing section
- Direct WhatsApp and phone contact integration
- Clean, brand-focused design
